# Quiz Interativo de Estruturas de Dados

## Descrição
Sistema interativo (CLI) que aplica conceitos fundamentais de Estruturas de Dados através de um quiz educacional.
O projeto integra teoria e prática, permitindo cadastro dinâmico de perguntas, fluxo controlado por fila, histórico navegável por pilha e acesso rápido via dicionário.
## Como Executar
```bash
python quiz_ds.py
```
